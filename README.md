## 📌 About

This repository is a growing archive of independent practice projects — small programs, simulators, tools, and mini-apps — each built to explore a concept, practice a language feature, or just solve a fun problem. Every project lives in its own folder with its own README explaining what it does and how to run it.

Nothing here is copied. If something looks rough around the edges, that's intentional — it's a real record of learning in progress, not a polished portfolio piece.

## 💡 Why This Repo Exists

I wanted one place to put things I build purely for practice — not for a class, not for a client, just for myself. Sharing it publicly because:

- It keeps me accountable to actually finish what I start.
- Seeing beginner-to-intermediate projects built honestly might help someone else starting out.
- It's a timestamped record of how my skills grow over time.

If any of this inspires you to build your own version of something here — that's the whole point.

## 🖥️ How to Use

Clone the repository:

```bash
git clone https://github.com/Md-Manam-Khan/Practice-Projects.git
cd Practice-Projects
```

Then open any project folder, read its README, and run it. Each project is self-contained.
